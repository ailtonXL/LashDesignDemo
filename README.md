# Lash Design Demo

Landing page Lash Atelier, com layout responsivo, apresentação de técnicas, seletor de efeitos e dúvidas frequentes.

## Visualizar

Abra `index.html` no navegador. Para testar todos os recursos localmente, execute `python3 -m http.server 8000` nesta pasta e visite http://localhost:8000.

O botão de agendamento prepara uma mensagem para copiar. Não envia dados nem reserva horários. O WhatsApp do estúdio ainda precisa ser conectado.

Foto ilustrativa: Unsplash. Fontes: Google Fonts (DM Sans e Italiana).
