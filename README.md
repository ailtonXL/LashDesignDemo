# Lash Design Demo

Landing page responsiva Lash Atelier, com apresentação de técnicas, seletor de efeitos e dúvidas frequentes.

## Visualizar

Abra `index.html` no navegador ou execute `python3 -m http.server 8000` e visite http://localhost:8000.

O agendamento prepara uma mensagem para copiar. Não envia dados nem reserva horários. Falta conectar o WhatsApp do estúdio.

Foto ilustrativa: Unsplash. Fontes: Google Fonts (DM Sans e Italiana).
